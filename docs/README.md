# docs

The Encore documentation is no longer authored in this repo. It's published at
https://encore.dev/docs.

The generated `ts/runtime/` directory is left here: it's the Encore.ts
runtime API reference, generated by TypeDoc from `runtimes/js/encore.dev` so
that generation stays next to its source.

This fork also maintains [the self-hosted dashboard design](self-host-dashboard/README.md),
including its implementation boundary, milestones and acceptance checklist.
It is a development proposal and implementation record, not documentation for
an available self-hosted Encore Cloud product.

## Regenerating `ts/runtime/`

```
cd runtimes/js/encore.dev && npm run docs
```

Don't edit those files by hand — TypeDoc overwrites the directory on every run,
and CI regenerates them and fails if the committed output has drifted from the
source. Change the doc comments in `runtimes/js/encore.dev` instead, then
regenerate and commit the result.
